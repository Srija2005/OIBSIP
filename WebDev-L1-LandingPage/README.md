# More Tea with Kutty Story

## About the Project
More Tea with Kutty Story is a responsive tea-themed landing page
that encourages visitors to relax, enjoy tea, and read little stories.

## Technologies Used
- HTML5
- CSS3
- Flexbox

## Features
- Responsive navigation bar
- Hero section
- About section
- Tea collection
- Kutty stories
- Contact section
