
# Temperature Converter

## About the Project
This Temperature Converter is developed as part of the Oasis Infobyte Web Development and Designing Internship – Level 1, Task 3.

It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- Enter a temperature value.
- Select Celsius, Fahrenheit, or Kelvin.
- Convert the input into all three temperature units.
- Display converted results with unit labels.
- Validate empty and invalid inputs.
- Handle absolute zero violations.
- Clear button to reset the values.
- Clean and responsive user interface.

## Conversion Formulas

- Celsius to Fahrenheit: (C × 9/5) + 32
- Celsius to Kelvin: C + 273.15
- Fahrenheit to Celsius: (F - 32) × 5/9
- Fahrenheit to Kelvin: (F - 32) × 5/9 + 273.15
- Kelvin to Celsius: K - 273.15
- Kelvin to Fahrenheit: (K - 273.15) × 9/5 + 32

## How to Run
1. Download or clone this repository.
2. Open the WebDev-L1-TemperatureConverter folder.
3. Open index.html in your browser.
4. Enter a temperature and select the input unit.
5. Click Convert to see the results.
